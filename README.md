# ⚽ Penalty Shootout Game

A simple soccer penalty shootout game built with HTML, CSS, and JavaScript.

## About

In this game, players attempt to score penalties by choosing a shot direction. The goalkeeper randomly dives left, center, or right to try to make a save. The objective is to score as many goals as possible.

## Features

- Choose between left, center, and right shots
- Random goalkeeper saves
- Score tracking
- Simple and responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
